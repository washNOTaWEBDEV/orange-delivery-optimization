# Tasks for humans

Raw data wanted. Suburb is required. Street address is welcome if you're happy to share it: it lets me place rural stops accurately. Keep addresses local, never on GitHub. No customer names.

1. **Timed deliveries.** Every delivery on a run: date, run, suburb, time of the delivery scan. About 10 working days each for Hamilton, Portland and Warrnambool, including a busy and a quiet week. If scan times aren't recorded, arrival and departure time at each stop.
2. **Route software output** for the same days: planned stop order, planned drive time and distance, actual depart and return times, total km.
3. **Daily totals per run:** left depot, back at depot, break times, end-of-day loading time, consignments delivered, stops, consignments left behind (by suburb), second driver used or not.
4. **Depot backlog:** before loading each day, consignments waiting per suburb for each run, and the date each arrived at the depot.
5. **Consignment counts per suburb per day per run**, 6-12 months if available.
6. **Town-to-run list:** the warehouse sort rules by suburb or postcode, for all three runs and the smaller ones.
7. **A few facts:** how often a run gets a second driver and what triggers it, how often a Horsham consignment appears, where the depot is.-

If you can only get one thing: items 1 and 3.
